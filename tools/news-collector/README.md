# news-collector — DCニュース収集ツール

「DCトレンド研究」の記事作成を支援するデータ収集ツール。依存パッケージなし(Node 18+の標準機能のみ)。

## できること

1. **ニュース収集**: RSS + Google News検索から DC 関連ニュースを取得し、サイトの6カテゴリに自動分類・関連度スコアリング。収集済み記事は `seen.json` で記憶し重複を排除。市場調査レポート販売やセミナー告知などのPRは減点ワードで検出し、ダイジェスト・ドラフトには載せない(アーカイブには`penalty`付きで残る)。英語DC専門メディア発で分類できない記事は「海外DC動向」として扱う。
2. **記事ネタ選定**: カテゴリ別・スコア順のダイジェスト Markdown を毎回生成 → 何を記事化するか眺めて決められる。14日より古い記事には「⚠旧聞」マーカー付き。
3. **統計データの蓄積**: 追跡キーワード(液冷・電力・SMR等。英語シノニム込み)の出現回数を `trends.csv` に日次で蓄積 → 「市場データ・統計」カテゴリ記事の一次データになる。`count`(収集全体)と `curated`(DC専門メディア4誌のみ・検索バイアスなし)の2系列。
4. **週間まとめ記事のドラフト生成**: サイトのフロントマター形式(draft: true)で、トレンド表 + カテゴリ別注目ニュース + アイキャッチ作成メモ入りのドラフトを出力。

## 使い方

**ダブルクリック(推奨)**: リポジトリ直下のバッチファイルを実行すると、収集後に結果ファイルが自動で開く。

- `📰ニュース収集・日次.bat` — 収集 + ダイジェストを開く(毎日)
- `📝週間まとめ作成・週次.bat` — 収集 + 週間まとめ記事ドラフトを開く(週1回)

**コマンドライン**:

```bash
npm run news          # 収集 + ダイジェスト生成(毎日 or 数日おきに実行)
npm run news:draft    # 収集 + 直近7日分から週間まとめ記事ドラフト生成
node tools/news-collector/collect.mjs --draft --days 14   # 期間を変える
node tools/news-collector/collect.mjs --draft --no-collect # 収集せずドラフトのみ
```

## 出力ファイル

| パス | 内容 |
|------|------|
| `data/archive/items-YYYY-MM-DD.json` | その日に収集した記事の全データ(分類・スコア付き) |
| `data/digest/digest-YYYY-MM-DD.md` | 記事ネタ選定用ダイジェスト |
| `data/trends.csv` | キーワード出現数の時系列(date,keyword,count,curated) |
| `data/drafts/weekly-dc-news-YYYY-MM-DD.md` | 週間まとめ記事ドラフト |
| `data/seen.json` | 収集済み記事のキー(重複排除用・直近5000件) |

## 自動実行(タスクスケジューラ登録済み)

| タスク名 | スケジュール | 内容 |
|---------|------------|------|
| DCトレンド研究 ニュース収集(日次) | 毎朝 8:00 | 収集のみ(バックグラウンド) |
| DCトレンド研究 週間まとめドラフト(週次) | 毎週日曜 8:30 | 収集 + ドラフト生成 |

- 実行ログは `data/collect.log` に追記される。PCがオフだった場合は次回起動時に実行される
- 時刻変更・削除は「タスクスケジューラ」アプリ(taskschd.msc)から
- 自動実行とダブルクリック実行が同日に重なっても、重複排除により問題なし

## 運用の流れ

1. 毎日〜数日おきに `npm run news` を実行(トレンドデータが日次で貯まる)
2. ダイジェストを見て単発記事のネタを拾う
3. 週1回 `npm run news:draft` → ドラフトの `TODO` コメント部分に解説を加筆
4. **必ず一次ソースを確認**(Google News経由はリダイレクトURL。リンクは一次ソースに貼り替え推奨)
5. 加筆済みドラフトを `src/content/articles/` に移動し、`draft: false` にして公開

## カスタマイズ

- **収集ソースの追加**: `sources.json` に RSS URL を追記(`baseScore` は専門メディアなら 3、汎用ソースなら 0。検索クエリ由来のフィードには `"search": true` を付けるとトレンドの `curated` 集計から除外される)
- **減点ワード**: `sources.json` の `penalties`(レポート販売・セミナー告知等のPR対策。負のスコアを加算)
- **分類キーワード**: `collect.mjs` の `CATEGORIES` を編集
- **トレンド追跡キーワード**: `collect.mjs` の `TREND_KEYWORDS` を編集(ラベル+シノニム形式。追加した日から集計開始)

## 注意

- `data/trends.csv` と `data/archive/` は記事の一次データなので **gitにコミットして残すのを推奨**
- Google News の検索RSSは仕様変更されることがある。取得失敗はダイジェスト冒頭に ⚠ で表示される
